# Монетка — учёт личных финансов

Веб-приложение (PWA): счета, записи доходов и расходов, бюджеты, цели, долги, регулярные платежи,
напоминания, отчёты по категориям и синхронизация через Google Диск.

Откройте приложение по ссылке и нажмите «Установить приложение» в браузере — оно появится
на рабочем столе телефона или компьютера и будет работать без интернета.

Данные хранятся в браузере на устройстве. При входе через Google копия сохраняется в скрытой
папке приложения на вашем Google Диске — другие пользователи и владелец приложения её не видят.

Иконки: [Lucide](https://lucide.dev) (ISC). Перелистывание разделов: [Swiper](https://swiperjs.com) (MIT), файлы в `vendor/`.
